# CampusX AI

A modern AI-powered hackathon prototype that helps college students discover complementary teammates from different departments and form multidisciplinary project teams.

## Features
- Project idea intake and AI-driven skill analysis
- Team recommendation engine using demo student profiles
- Skill gap detection and fill-in student suggestions
- AI-generated project timeline and role mapping
- Modern single-page interface built with React + Vite

## Run locally
```bash
npm install
npm run dev
```

## Tech stack
- React
- Vite
- CSS custom styling

## Demo flow
Project Idea → Project Analyzer Agent → Required Skills → Student Matcher Agent → Team Builder Agent → Skill Gap Detection Agent → Project Planner Agent → Final Multidisciplinary Team
